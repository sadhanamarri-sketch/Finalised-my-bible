# Verse Scroll's bundled data

Everything under `app/src/main/assets/verse_scroll/` is generated by these scripts (Python 3 with
numpy and Pillow):

- `scenes/*.webp`: the painted backgrounds, drawn entirely with code by `scenes.py`. Which scenes
  ship (kind, palette, seed) is listed in `scene_list.py`, along with the kinds left out.
- `scenes.json`: for each scene, how much it is dimmed under the text in dark themes (`kd`) and light
  ones (`kl`), plus where its small moving touches go (sun, horizon, mist, moon, light source, color
  glows, wind).
- `discover.tsv`: the verses Discover deals from, with their weights.

To regenerate:

```sh
python3 render_scenes.py /tmp/scenes                    # paints the scenes, writes meta.json and contact sheets
python3 fit_veils.py /tmp/scenes json > /tmp/veils.json # measures the dimming each scene needs
python3 check_veils.py /tmp/scenes /tmp/veils.json      # lowest contrast per app theme, for the record
python3 make_assets.py eng-kjv.osis.xml cross_references.txt /tmp/scenes /tmp/veils.json \
    ../../app/src/main/assets/verse_scroll
```

`eng-kjv.osis.xml` and `cross_references.txt` are the same files the app downloads (see
`KjvImporter` and `CrossReferenceImporter`).

The dimming targets: the verse stands out by at least 4.5:1 and the context lines and reference by
3:1, measured over the worst 3% of pixels anywhere text can sit. With motion on, the app adds a small
margin (`SceneLayer.drawVeil`) to cover the brighter patches the slow zoom can bring behind the text.
